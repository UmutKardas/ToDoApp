<h1>ToDoApp</h1>

<img src="https://github.com/user-attachments/assets/f3981d05-a582-407e-ac42-787082de72d3" alt="ToDoApp Screenshot">

<p>ToDoApp is an application that allows you to easily manage your tasks. With a user-friendly interface built using SwiftUI, you can create, edit, and mark tasks as complete.</p>

<h2>Features</h2>
<ul>
    <li>Create, edit, and delete tasks.</li>
    <li>Organize tasks into categories.</li>
    <li>Mark tasks as complete.</li>
    <li>User-friendly interface.</li>
</ul>

<h2>Structures Used</h2>
<ul>
    <li><strong>SwiftUI</strong>: For building the user interface.</li>
    <li><strong>MVVM</strong>: For organizing the code structure.</li>
    <li><strong>Swift Data</strong>: For managing and storing data.</li>
</ul>
